# esp32-play

DIY hardware projects built around the ESP32.

| Project | What it is |
|---------|------------|
| [focus-dock](focus-dock/) | Desk companion: knob-driven focus timer, real CO2 monitor, presence radar with stand-up reminders, and a small web dashboard. |

Each project folder is a self-contained PlatformIO project with its own parts list, wiring table and flashing steps.
